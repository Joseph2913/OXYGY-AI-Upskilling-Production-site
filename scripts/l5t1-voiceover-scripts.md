## Slide 7 — RCTF: The Five-Stage Pipeline (progressive-reveal, 5 clips)

### 7a — Setup (Prototype)
**File:** `l5t1-s07-setup.mp3`

Now let's walk through the pipeline. Five stages, each building the foundation for the next. First: Prototype. This is where you define and draft what you're building — before a single line of code is written. Your brief, user flow, and feature list take shape here, in plain language, through iteration. Without this stage, you build the wrong thing quickly and then rebuild it slowly. Click next for the second stage.

**~68 words**

### 7b — Reveal 1 (Version Control)
**File:** `l5t1-s07-reveal1.mp3`

Second: Version Control. This is how you save, track, and restore your build as it evolves. Typically that means a GitHub repository. Version control means you can try something, break it, and return to a known good state — without starting over. Without it, a single mistake can require a complete rebuild from scratch.

**~52 words**

### 7c — Reveal 2 (Logic)
**File:** `l5t1-s07-reveal2.mp3`

Third: Logic. This is the actual build layer — where your description becomes a working application. This is the vibe coding stage: you direct an AI builder in plain language and it generates the implementation. The key is choosing a Logic tool that connects to your Version Control and has a deployment path. The wrong tool here means no history and no way to ship.

**~62 words**

### 7d — Reveal 3 (Data)
**File:** `l5t1-s07-reveal3.mp3`

Fourth: Data. This is where your application's information lives — user profiles, progress, saved state. Every personalised experience depends on a database, not a spreadsheet or a local file. Without this stage, each user sees the same blank slate every time they open the application. Personalisation is impossible without persistent data.

**~50 words**

### 7e — Reveal 4 (Deploy)
**File:** `l5t1-s07-reveal4.mp3`

And fifth: Deploy. This is what turns a build into a product. Deployment means getting the finished application in front of the people who need it — at a URL they can visit, on any device, independently of your laptop. Without this, the application only runs on your machine. Nobody else can use it. Those are your five stages — and the order matters.

**~62 words**
